# Security

Do not include credentials, private keys, installation logs, or Home Assistant
storage files in public issues. Report vulnerabilities through GitHub's private
vulnerability reporting feature when available. Otherwise contact the repository
owner privately through their GitHub profile before sharing exploit details.

Only the latest integration version is supported. The card currently requires
unencrypted local HTTP configuration and MQTT. Its setup form requires explicit
confirmation before transferring broker credentials. See the README for the
network trust boundary and credential storage behavior.
